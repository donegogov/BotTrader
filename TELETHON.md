# 📱 TELETHON — упатство (како ботот чита сигнали)

Ова упатство објаснува **точно што прави Telethon**, зошто е потребен, и како да се најавиш чекор по чекор.

---

## 🧠 Што е Telethon?

**Telethon** е програма што му овозможува на Python да зборува со Telegram **како обичен корисник** — исто како што тоа го прави твојата Telegram апликација на телефон.

Кога се најавуваш во Telegram на телефон, **ти** гледаш канали на кои си член.
Кога се најавуваш во BotTrader, **бот** гледа истите тие канали — со твоите очи.

**Не е bot.** Не е API. Не е сервер. Тоа е **твојот акаунт**.

---

## 🔐 Зошто е безбедно?

| Што | Како |
|---|---|
| Каде одат податоците? | **Никаде.** Сè останува на твојот компјутер. |
| Дали некој го гледа? | **Не.** Ниту PremTradingSig, ниту кој било друг. |
| Дали може да праќа пораки? | **Не.** Програмата само чита. |
| Дали може да брише контакти? | **Не.** Само чита пораки од еден канал. |
| Што ако го изгубиш лаптопот? | Избриши ја сесијата од Telegram: **Settings → Devices → Terminate**. |

**Најважно:** твојот телефон и кодот **не се зачувуваат**. Се зачувува само „сесија" (како кога остануваш најавен во апликација).

---

## 🚀 Како да се најавиш — ЧЕКОР ПО ЧЕКОР

### Претходно: мора да си член на каналот

1. Отвори Telegram
2. Барај **PremTradingSig** (или отвори го линкот што ти го дал PremTradingSig)
3. Кликни **„Join"** / **„Приклучи се"**

⚠️ **Без членство, ботот НЕМА да работи** — ова е намерно. Само членови читаат сигнали.

---

### Чекор 1: Отвори терминал

| OS | Како |
|---|---|
| **Windows** | Start → `cmd` → ENTER |
| **macOS** | ⌘ + Space → `Terminal` → ENTER |
| **Linux** | `Ctrl + Alt + T` |

Оди во папката каде што е BotTrader:

```bash
cd патека/до/BotTrader
```

*(Windows: `cd C:\Users\ТвоеИме\Downloads\BotTrader-main`)*

---

### Чекор 2: Пушти најава

**Windows:**
```bash
python bot_trader.py --login
```

**macOS / Linux:**
```bash
python3 bot_trader.py --login
```

---

### Чекор 3: Внеси телефон

Ќе видиш:

```
================================================================
  Telegram најава
================================================================

  Ќе се најавиш со ТВОЈОТ телефонски број — истиот што го користиш
  во Telegram апликацијата. Кодот ќе ти дојде во Telegram, не SMS.

  ⚠️  Ова е твојот личен акаунт. Програмата само ГИ ЧИТА пораките
      од каналот. Не праќа ништо, не ги менува твоите контакти.

  Телефонски број (со +389...): 
```

Напиши го твојот број **со државен код и плус**:

```
+38970123456
```

> ⚠️ **Мора со `+389`** (или твојот државен код). Ако напишеш `070123456` без `+389`, нема да работи.

Притисни **ENTER**.

---

### Чекор 4: Внеси код

Веднаш потоа, во твојата **Telegram апликација** (на телефон или компјутер) ќе ти дојде порака:

> **Telegram**: Your login code: **12345**

Тоа е **5 цифри**. Не е SMS — доаѓа во самата Telegram апликација.

Во терминалот ќе видиш:

```
  Код од Telegram: 
```

Напиши ги 5-те цифри (пример `12345`) и **ENTER**.

> ⏱ Кодот важи 5 минути. Ако истече, пушти `--login` повторно.

---

### Чекор 5: Ако имаш двофакторска (2FA)

Ако имаш **Two-Step Verification** во Telegram (лозинка), ќе те праша:

```
  Двофакторска лозинка (2FA): 
```

Напиши ја **твојата Telegram лозинка** (не API, не банка — таа што ја внесуваш кога се логираш во Telegram на нов телефон).

> 💡 Ако не знаеш дали имаш 2FA: Telegram → Settings → Privacy and Security → Two-Step Verification.

---

### Чекор 6: Готово ✅

Ќе видиш:

```
  ✅ Најавен како: Твое Име (@tvojusername)

  Следно:  python bot_trader.py --setup
```

**Тоа е сè.** Сесијата е зачувана — **нема да те праша повторно**.

## 📁 Што се зачува на компјутерот?

| Фајл | Што содржи | Безбедност |
|---|---|---|
| `telegram_session.session` | Твојата најава (како „остани најавен") | Не го споделувај |
| `config.json` | Поставки (коини, левериџ, API клучеви) | Не го споделувај |

**Не се зачувува:** телефонски број, код, лозинка. Само сесијата.

## ⚠️ Најчести проблеми

### „Телефонски број (со +389...)" — не прифаќа
- Мора да почнува со `+` (пример `+38970123456`)
- Без празни места, без цртички

### Не добивам код
- Провери во **Telegram апликацијата** (не SMS!)
- Ако си најавен на повеќе уреди, кодот доаѓа на **сите**
- Ако не доаѓа: почекај 30 сек, пушти `--login` повторно

### „SessionPasswordNeededError" / бара лозинка
- Имаш 2FA. Внеси ја лозинката од Telegram → Settings → Privacy → Two-Step Verification

### „Не можам да го најдам каналот"
```
  ❌ Не можам да го најдам каналот: @premtradsignal
```
- **Не си член** → приклучи се прво (Чекор 0)
- Или погрешно име → провери `config.json` → `"channel": "@premtradsignal"`

### „Немаш пристап до каналот"
- Каналот е приватен и не си член
- Побарај invite линк од PremTradingSig

### „FloodWaitError: A wait of X seconds is required"
- Telegram те блокирал привремено (превише обиди)
- Почекај X секунди и пушти повторно

### Сакам да се одјавам
```bash
python bot_trader.py --logout
```
Брише сесијата. Следен пат пак `--login`.

### Сакам целосно да ја избришам сесијата од Telegram
Telegram → Settings → Devices → најди го BotTrader → **Terminate**

## 🔄 Како работи по најавата?

```
1. Ботот е најавен како ТИ
2. Чека нова порака во каналот
3. Кога ќе дојде #signal порака → ја чита
4. Проверува: дали симболот е во твоите коини (TRADE_COINS)
5. Ако да → праќа нарачка на твојот Bybit/Binance
```

**Само членови** добиваат пораки, затоа **само членови** можат да ги читаат. Тоа е заштитата.

## 💡 Често поставувани прашања

**Дали можам да го користам на 2 компјутери?**
Да, но на секој треба `--login` одделно (секој има своја сесија).

**Дали ботот работи кога компјутерот е исклучен?**
Не. Мора да е пуштен (`python bot_trader.py`) за да слуша.

**Дали може да ми ги украде парите?**
Не — програмата не знае твои пари освен API клучот што **ти** го внесуваш, и тој е без Withdraw дозвола.

**Дали Telegram ќе ме блокира?**
Не, ако не правиш масовни акции. Читање на еден канал е сосема нормално.

**Што ако го сменам телефонскиот број?**
Пушти `--logout` па `--login` со новиот број.
